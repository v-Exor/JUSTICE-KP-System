# JUSTICE-KP Role Matrix

| Role | Main Permissions |
|---|---|
| System Admin | Full access, users, settings, backups |
| Barangay Secretary | Cases, transcripts, evidence, Phase 2-4 work |
| Lupon Chair/Captain | Case review, evidence review, official decisions, forms |
| Lupon Member/Mediator | Assigned case/hearing review and mediation workflow |
| Researcher/Auditor | Phase 5 validation, metrics, anonymized exports |
| Viewer | Read-only non-sensitive case summaries and forms |

Sensitive cases require elevated permissions for transcripts, evidence, referrals, and generated forms.
